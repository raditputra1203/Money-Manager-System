# Money Manager System

A web-based personal finance management system that allows users to record, track, and analyze financial transactions.

## 📌 Features
- User Authentication (Register & Login)
- Transaction Input (Income & Expense)
- Wallet Balance View
- Transaction History
- Multiple Transaction Books
- Financial Analytics (Charts)

## 🧑‍💻 Technology
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js (Express)
